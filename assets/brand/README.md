# RMG Labs brand kit (website)

Colors: ink navy #14181F, blue #2F7BFF / #4FB6FF / #1F5BE0, ice #BEE6FF, text #F2F5FA, muted #9FB2D0.
Fonts used in the logo (already converted to outlines, nothing to install): Yellowtail (script), Space Grotesk Medium (LABS + tagline).

- logo/svg   Vector logos, transparent background. Use -dark on dark pages, -light on light pages.
  - rmg-labs-logo-*        with tagline (hero, footer)
  - rmg-labs-logo-notagline-*   compact (site header)
  - rmg-labs-peak-*        mountain mark only
- logo/png   Same logos as PNG (1200px wide, plus @2x).
- icons      favicon.ico/.svg, apple-touch-icon.png, icon-192, app-icon-512, icon-maskable-512 (PWA / app store art base).
- social     og-image.png (1200x630) for link previews.
- site.webmanifest, head-snippet.html (copy into <head>), preview.html (open to review everything).
