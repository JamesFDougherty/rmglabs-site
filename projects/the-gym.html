The GYM

In development

A complete membership app for a local pay-as-you-go training gym: members join from their phone, the owner approves them, and trainers run and log every workout.

What it does

Built so it can be set up for any gym: the name, logo, hours and plans are all settings.

  • Invite-code sign-up with a six-step health and intake form
  • Owner approval flow with an instant phone alert for each new applicant
  • Open hours and live "staffed now" status
  • Trainer session timer with pause, plus a searchable exercise library
  • One-tap 911 and emergency-contact calling for trainers
  • Admin reports, member files and a security log of failed sign-ins
